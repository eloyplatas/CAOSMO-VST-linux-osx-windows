Caosmo 0.5

Manual de usuario · User Manual — Eloy Platas · GNU GPL v3 · English below

Introducción

Caosmo es un sintetizador polifónico que no reproduce ondas fijas ni muestras: cada nota pone en marcha un sistema dinámico y lo que oyes es la trayectoria de ese sistema, resuelta muestra a muestra. Osciladores que se sincronizan entre sí, muelles no lineales empujados al límite, atractores extraños, mapas iterados, un circuito electrónico caótico, una reacción química en un anillo de células, una cuerda frotada, un bucle de retardo con memoria y un mapa que engrana frecuencias como dientes de un engranaje.

El resultado es un instrumento que se comporta más como un objeto físico que como un oscilador: tiene zonas de calma y zonas de turbulencia, responde de forma distinta según cómo llegues a un ajuste, y nunca suena exactamente igual dos veces.

Origen

Caosmo es una reimplementación funcional del concepto descrito en la documentación pública de Fragua, de Pura Belia: un sintetizador de caos de tres capas por nota con doce motores. Todo el código, los nombres, la interfaz, los presets y este manual son propios; no contiene código ni recursos de Fragua. Es una obra independiente sin relación con Pura Belia.

El caos para músicos

No hace falta saber matemáticas para tocar Caosmo, pero cinco ideas te ahorrarán mucho tiempo.

Sistemas dinámicos

Un sistema dinámico es un conjunto de variables (posición, velocidad, temperatura, fase…) y una regla que dice cómo cambian en el tiempo. Un oscilador sinusoidal es el sistema dinámico más aburrido posible: da vueltas en círculo para siempre. Los motores de Caosmo son sistemas con no linealidades: términos al cubo, valores absolutos, saturaciones, productos entre variables. Esas no linealidades son las que permiten comportamientos complejos.

Atractores

Si dejas correr un sistema con rozamiento, su estado acaba en una región concreta: el atractor. Puede ser un punto (el sistema se para: silencio), un ciclo (el sistema repite una forma: un tono periódico), un toro (dos ciclos superpuestos: un tono con batidos) o un atractor extraño (el sistema nunca se repite pero nunca se escapa: un sonido vivo, rugoso o ruidoso). Los retratos de fase del SCOPE muestran literalmente el atractor de cada capa.

Sensibilidad a las condiciones iniciales

En un sistema caótico, dos estados casi idénticos se separan exponencialmente. Por eso Caosmo inicia cada nota con una semilla distinta: dos notas iguales seguidas no son idénticas, y un acorde no suena como copias transportadas. Si quieres repetibilidad, varios motores tienen el menú Note → Free, que conserva el estado entre notas en lugar de reiniciarlo.

Bifurcaciones

Al mover un parámetro de control (K, Gamma, Chaos, Alpha, Sharp, R…) el tipo de atractor puede cambiar de golpe: un tono se desdobla en su suboctava (duplicación de periodo), aparece un batido, o el sonido se rompe en ruido. Esos puntos son bifurcaciones. Son el mejor material del instrumento: modula lentamente alrededor de ellas con una VENV o un LFO y oirás el sistema decidir. Muchas fronteras tienen histéresis: el punto donde el sistema se rompe al subir no coincide con el punto donde se recompone al bajar.

Sincronización y enganche

Varios motores (Kuramoto, Circle Map, Mackey-Glass) tratan de engancharse: osciladores que acaban latiendo juntos, frecuencias que se quedan atrapadas en proporciones simples (1:1, 2:3, 3:4). Entre zonas de enganche hay regiones cuasiperiódicas y caóticas. Ahí está el carácter metálico, vocal o tembloroso de esos motores.

Cómo protege Caosmo al sistema

Un sistema no lineal puede escaparse al infinito. Cada motor vigila su estado: si una variable se dispara o deja de ser un número válido, el motor se reinicia en silencio en una posición segura. Oirás como mucho un pequeño clic, nunca una explosión de nivel. Además, todos los motores con altura limitan su paso de integración para mantenerse estables en las notas agudas.

Arquitectura y flujo de señal

Cada nota que tocas reserva una voz. Dentro de la voz, cada capa con motor tiene su propia cadena completa:

  1. Motor: genera la señal resolviendo su sistema, afinado a la nota si es un motor con altura.
  2. Sub 1 (otra instancia del mismo motor, 1–3 octavas abajo) y Sub 2 (seno 1–2 octavas abajo) se suman al motor.
  3. Filtro de 14 tipos.
  4. Envolvente (VCA, y en modo LPG también el filtro), escalada por la velocidad.

Después las voces de cada capa se suman en el bus de la capa, donde se aplican EQ, drive, width, bass mono, pan, nivel y los envíos a los buses FX A–C. Los buses de capa y los retornos de FX se suman, pasan por el rack DELUGE FX (si está activo) y por la cadena master.

Esta división importa para la modulación: lo que ocurre dentro de la voz (pitch, filtro, motor, envolvente, nivel) puede modularse por nota; lo que ocurre en el bus de la capa (EQ, drive, width, pan, envíos) solo puede modularse con fuentes globales, porque ahí ya no existen notas separadas.

Voces y robo de voces

Voices fija la polifonía máxima (1, 4, 8, 16, 32 o 64). Cuando se agotan, Caosmo roba primero una voz libre, después la voz soltada más antigua y en último caso la más antigua sonando. Con Voices = 1 el sinte es monofónico: con Legato activo las notas ligadas no reinician las envolventes y Glide desliza la altura (Fingered: solo al ligar; Always: siempre).

Semilla por nota

Cada nota recibe un número aleatorio propio que usan los motores para su estado inicial, el drift, la fuente Note Random y el reparto estéreo de Voice Spread. Por eso un mismo preset tiene «vida» sin necesidad de modulación.

  • Arrastrar cambia el valor; Shift + arrastrar hace ajuste fino.
  • Doble clic abre la entrada numérica.
  • Rueda: ajuste según Settings (Fine, Coarse u Off, para no mover nada al desplazarte).

Kuramoto

El sistema. Yoshiki Kuramoto describió en 1975 cómo una población de osciladores con frecuencias distintas puede sincronizarse cuando se acoplan: luciérnagas que acaban destellando a la vez, células del marcapasos cardíaco, aplausos que se ponen de acuerdo. Cada oscilador gira a su frecuencia natural ωᵢ y es atraído hacia la fase media del grupo:

dθᵢ/dt = ωᵢ + K · r · sin(ψ − θᵢ)

donde r (0–1) mide cuánto coinciden las fases y ψ es la fase media.

En Caosmo. Hasta 12 osciladores de fase. Sus frecuencias naturales se reparten alrededor de la nota según Ratio y Spread, y se normalizan para que su media sea la nota. Con K bajo cada oscilador va a su aire: oyes un racimo de parciales que baten. Al subir K aparece un umbral crítico en el que el grupo se bloquea y el sonido se convierte en un tono único, limpio y cristalino. Ese umbral tiene histéresis: subir y bajar K no pasa por los mismos sonidos.

Parámetro Rango (defecto) Qué hace
K 0–15 (2) Fuerza de acoplamiento. Escala con la nota y con Spread, así que el umbral es parecido en todo el teclado.
Spread 0–1 (0,5) Dispersión de las frecuencias naturales. Más spread: parciales más separados y K más alto para bloquear.
N Osc 3–12 (6) Osciladores activos. Los que entran o salen lo hacen con un fundido de 20 ms, así que se puede modular sin clics.
Out Mean, Coherent (Mean) Mean: la suma de todos. Coherent: la suma ponderada por el grado de sincronía; casi silencio desincronizado y pleno al bloquearse.
Ratio Asymmetric, Linear, Golden, Harmonic, Random (Asymmetric) Reparto de frecuencias. Linear: equiespaciado. Asymmetric: cuadrático, más denso abajo. Golden: posiciones por la razón áurea, máximamente inarmónicas. Harmonic: 1, 1+Spread, 1+2·Spread…; con Spread = 1 es la serie armónica. Random: fijo pero irregular.

Puntos dulces. Harmonic con Spread 1 y K de 2 a 6: un órgano que se desafina y se recompone. Golden con K cerca del umbral y Out = Coherent: campanas que aparecen y desaparecen. Modula K con un LFO lento o con un atractor para pads que entran y salen de fase (preset Glass Synchrony).

Duffing

El sistema. Un muelle cuya rigidez crece con el desplazamiento y que tiene dos posiciones de reposo (un doble pozo), empujado por una fuerza periódica:

ẍ + δẋ − x + k·x³ = γ·f(ωt)

Con poca fuerza la masa oscila dentro de un pozo: un tono redondo. Con más fuerza salta de un pozo a otro, a veces con regularidad (subarmónicos) y a veces de forma caótica.

En Caosmo. La escala de tiempo sigue la nota; la fuerza oscila a Omega veces la nota. La integración es Runge-Kutta de cuarto orden por muestra.

Parámetro Rango (defecto) Qué hace
Gamma 0–1 (0,3) Amplitud de la fuerza. Es el control principal del caos: de tono estable a saltos.
Delta 0,01–1 (0,1) Rozamiento. Bajo: resonante y salvaje. Alto: amortiguado y dócil.
Omega 0,25–4 (1) Frecuencia de la fuerza respecto a la nota. 1 = resonancia; 0,5 y 2 dan subarmónicos y armónicos; valores no enteros, batidos.
Stiff 0,5–3 (1) Rigidez no lineal. Mueve la posición de los pozos y la brillantez.
FB 0–1 (0) Suma la posición a la fuerza: autoexcitación, más inestable.
Out Position, Velocity, Blend (Position) Variable que escuchas. Velocity es más brillante (es la derivada).
Drive Sine, Square, Triangle, Saw, Noise (Sine) Forma de la fuerza. Square y Saw excitan más armónicos; Noise (filtrado a Omega × nota) da un sonido soplado, de flauta o de viento.

Puntos dulces. Bajo: Gamma 0,2–0,35, Delta 0,15, Omega 1, Out Position (preset Double Well Bass). Flauta: Drive Noise, Gamma 0,5, Out Velocity (Duffing Flute). Modula Gamma con la velocidad para que tocar fuerte haga saltar la masa entre pozos.

Sprott

El sistema. Julien C. Sprott buscó los sistemas caóticos más sencillos posibles. Este es un flujo jerk (la derivada de la aceleración):

x‴ = −a·ẍ − ẋ + |x| − 1

Con a alto el sistema describe un ciclo limpio; al bajar a pasa por una cascada de duplicaciones de periodo (el tono cae a la suboctava, luego a la suboctava de la suboctava…) hasta el caos.

En Caosmo. Chaos, Damp y FB se combinan en el coeficiente a, siempre dentro de la ventana en que el sistema no se escapa. La escala de tiempo sigue la nota y Omega la multiplica.

Parámetro Rango (defecto) Qué hace
Chaos 0,1–3 (1) Baja el coeficiente a: de tono periódico a duplicaciones y turbulencia.
Damp 0,1–3 (1) Sube a: más amortiguado, más estable. Contrapeso de Chaos.
Omega 0,25–4 (1) Multiplica la escala de tiempo: 2 = una octava arriba (aproximadamente, el periodo depende del atractor).
FB 0–1 (0) Añade un término sinusoidal que retuerce la órbita y limita el caos máximo.
Out X, Y, Z, Blend (X) Coordenada que escuchas. X es la más suave; Z, la más áspera.

Puntos dulces. Sube Chaos despacio desde 0,1 con Damp en 1: oirás cada duplicación de periodo. Una VENV larga en Chaos es el corazón de la categoría Bifurcations.

Lorenz + Rössler

El sistema. Dos de los atractores extraños más famosos. Lorenz (1963), un modelo simplificado de convección atmosférica con sus dos «alas de mariposa»:

ẋ = σ(y − x) ẏ = x(ρ − z) − y ż = xy − βz (ρ = 28, β = 8/3)

Rössler (1976), una espiral que se pliega sobre sí misma:

ẋ = −y − z ẏ = x + a·y ż = b + z(x − c) (a = b = 0,2)

En Caosmo. Los dos corren a velocidades fijas (Lorenz lento y gruñón, Rössler alrededor de 190 ciclos por segundo) y se mezclan. No siguen la nota: usa Sub 2, un filtro resonante o Pitch en los subs para dar altura.

Logistic / Hénon

El sistema. Dos mapas: reglas que calculan el siguiente valor a partir del actual. El mapa logístico (May, 1976) es la ecuación de población más famosa de la teoría del caos:

xₙ₊₁ = r·xₙ·(1 − xₙ)

El mapa de Hénon (1976) es su versión bidimensional:

xₙ₊₁ = 1 − a·xₙ² + yₙ yₙ₊₁ = b·xₙ

En Caosmo. Con Clock en Per Sample (el modo por defecto) los dos mapas se iteran una vez por muestra. A 48 kHz eso produce ruido con estructura: granulado, polvoriento, con tonos agudos fijos cuando el mapa cae en una ventana periódica (por ejemplo r ≈ 3,83 da un ciclo de periodo 3). En ese modo no sigue la nota; con los relojes Note sí (ver la tabla).

Chua

El sistema. El circuito de Leon Chua (1983) fue el primer circuito electrónico construido para demostrar el caos. Tiene una resistencia no lineal por tramos y produce el famoso atractor de doble espiral:

Mackey-Glass

El sistema. Michael Mackey y Leon Glass propusieron en 1977 un modelo de producción de células sanguíneas con retardo: lo que el cuerpo produce hoy depende de lo que había hace un tiempo τ.

dy/dt = β · y(t−τ) / (1 + y(t−τ)ⁿ) − γ·y

Con retardos cortos el sistema oscila; con exponentes n altos la oscilación se duplica y se vuelve caótica.

En Caosmo. El retardo τ se autoafina: un detector de periodo ajusta el bucle hasta que la oscilación coincide con la nota. El resultado son tonos de realimentación con altura estable que pueden romperse en caos.

Circle Map

El sistema. El mapa del círculo es el modelo más simple de dos osciladores que intentan engancharse, como los dientes de dos engranajes o un columpio empujado:

En Caosmo. El mapa se itera a un ritmo ligado a la nota y su fase se convierte en una onda. Un segundo mapa (el engranaje esclavo) corre al doble de ritmo y se acopla al primero.

Ecosystems

El sistema. Seis modelos de la biología y la química, tomados de los SLUGens de Nick Collins y los ChaosUGens de Till Bovermann:

  • FitzHugh-Nagumo: una neurona simplificada. Por debajo de un umbral de corriente no hace nada; por encima, dispara picos regulares.
  • Brusselator: un reloj químico teórico. Por encima de la bifurcación de Hopf oscila en un ciclo límite.
  • Oregonator: el modelo de la reacción de Belousov-Zhabotinsky, el famoso cóctel químico que cambia de color en ciclos.
  • Lotka-Volterra: presas y depredadores. Cuando hay muchas presas crecen los depredadores, que luego se las comen.

Membrane

El sistema. Una pelota que cae y rebota, como el UGen TBall de Dan Stowell, golpeando un cuerpo resonante modal. Cada golpe excita hasta 16 modos con las proporciones de una membrana circular, una placa cuadrada, una barra libre o una campana.

Snapshots y morph

El EQ guarda hasta cuatro curvas (snapshots A–D):

  1. Ajusta una curva en A.
  2. Selecciona B: la primera vez, B copia la curva actual. Modifícala.
  3. Repite con C y D si quieres.
  4. EQ Morph (0–100 %) recorre los snapshots usados en orden A → B → C → D, interpolando frecuencias de forma logarítmica y ganancias de forma lineal.

Al elegir un snapshot el morph se coloca sobre él, para que oigas lo que editas. RST vuelve a un único snapshot plano. EQ Morph es un destino de modulación (con fuentes globales): un LFO lento sobre él da filtrados de varias bandas que se mueven a la vez.

Keytrack

Una curva dibujable que convierte la nota MIDI (de 0 a 127) en un valor de modulación. Doble clic añade un punto y clic derecho lo borra. La fuente Keytrack entrega ese valor. Por defecto es una recta, pero puedes hacer que solo las notas agudas modulen, que el centro del teclado sea neutro o que cada zona tenga un comportamiento distinto. La categoría Strata usa curvas que vuelven inestables las notas altas.

Macros

Cinco controles globales (0–100 %) en la barra inferior (M1–M5), pensados para tocar y automatizar. Clic derecho en un control → Send to Macro crea la ruta directamente. La vista MACROS de la página MATRIX muestra qué mueve cada una. Todos los presets de fábrica tienen las cinco macros asignadas a algo audible.

MIDI, MIDI Learn y MPE

  • MIDI Learn: clic derecho en un control → MIDI / MPE → MIDI Learn y mueve un controlador. Caosmo crea una ruta CC en la matriz, así que se guarda con el preset y puedes ajustar su cantidad y curva.
  • Canal por capa: en LANE, para splits o tres partes desde tres pistas MIDI.
  • PB Range: rango del pitch bend global, 0–24 semitonos (2).
  • MPE: activa Lower (canal maestro 1, notas en 2–16) o Upper (canal maestro 16, notas en 1–15). Cada nota recibe su propio bend (MPE PB Range, 0–96 semitonos, 48 por defecto), presión y slide (CC 74), disponibles como fuentes por nota. Con MPE se ignoran los canales de capa.

En REAPER, para MPE pon la pista en modo de entrada MIDI All channels y no fuerces un canal en el envío al plugin.

DELUGE FX

El rack DELUGE FX contiene los efectos del firmware comunitario del Synthstrom Audible Deluge, copiados de su repositorio de código abierto y compilados tal cual: la misma aritmética de punto fijo de 32 bits, los mismos bloques de 64 muestras y las mismas tablas. Es una inserción situada entre la suma de capas y FX y la cadena master.

Los controles usan la escala 0–50 de los menús del Deluge (−25 a +25 en los bipolares) y pasan por las mismas conversiones del firmware. Con todos en su posición neutra el nivel no cambia.

El orden interno es el del Deluge: stutter → Mod FX → EQ → delay → decimación y bitcrush → saturación → reverb → compresor.

Cómo se hicieron

Los presets se describen en archivos de texto y un programa los genera, los renderiza y los mide. Cada preset se nivela automáticamente a unos −18 dBFS RMS y se comprueba que su pico verdadero no supere −0,8 dBTP; además se mide cuánto evoluciona el sonido en el tiempo, para que los marcados como Evolving o Chaotic lo sean realmente. Por eso puedes recorrer el banco sin sobresaltos de volumen.

Tutoriales

Cada receta parte del patch inicial: Settings → RESET TO INIT. Los valores son puntos de partida: escucha y corrige.

Un pad que se sincroniza

  1. L1 Engine Kuramoto. Ratio Harmonic, Spread 0,6, N Osc 8, Out Coherent.
  2. ENV GEN: Attack 1,5 s, Release 3 s.
  3. FILTER: LPF 24 dB, Cutoff 3 kHz, Res 20 %.
  4. MODULATORS: LFO 1 en Random Smooth, Rate 0,08 Hz. ASSIGN → clic en K (en MAIN). En la matriz, Amount 0,35.
  5. Sube K hasta oír que el sonido entra y sale del bloqueo.
  6. Envío FX1 a −8 dB (Reverb del bus A).

Para más vida: Drift Pitch Subtle y, en L2, el mismo motor con Ratio Golden y Level −9 dB.

Un bajo de doble pozo con mordida

  1. L1 Duffing: Gamma 0,28, Delta 0,18, Omega 1, Out Position.
  2. Voices 1, Legato On, Glide 40 ms.
  3. FILTER: Ladder, Cutoff 400 Hz, Res 35 %, LPG Amp + Filt.
  4. ENV GEN: Attack 2 ms, Decay 350 ms, Sustain 40 %.
  5. Matriz: Velocity → L1 Motor 1 (Gamma), Amount 0,3, Curve Exp. Tocar fuerte hace saltar la masa entre pozos.
  6. OUTPUT: Drive 25 % Tape, Bass Mono 120 Hz.

Percusión de arena y metal

Rendimiento y CPU

El coste depende de voces × capas × motor. Algunas pautas:

  • Los motores más ligeros son Maps, Noise, Logistic/Henon, Duffing, Sprott, Chua y Circle Map. Los más pesados, Lorenz Additive (con Engine HQ), Wave Grains con Count alto, Kuramoto con 12 osciladores y Gray-Scott.
  • Sub 1 duplica el coste del motor de esa capa; Sub 2 es gratis.
  • Los moduladores Poly cuestan una instancia por voz.
  • Baja Voices a lo que necesitas: 8 suele bastar para pads, 1–4 para bajos y leads.
  • Apaga Engine HQ si no usas Lorenz Additive o si vas justo de CPU.
  • Apaga con PWR las capas que no usas (Mute no ahorra CPU).
  • Los visualizadores solo consumen CPU con la ventana abierta; ciérrala o páusalos en Settings.
  • En el DAW, usa render/freeze de pista para mezclas grandes.

Cómo se hizo

Caosmo se construyó en cinco versiones, de un núcleo que se podía tocar a un instrumento completo con efectos y binarios para tres sistemas.

Investigación

El punto de partida fue la documentación pública de Fragua: su arquitectura de tres capas, la lista de motores, la descripción de cada control y las demostraciones publicadas. A partir de ahí cada sistema se reimplementó desde sus ecuaciones originales en la literatura científica (Kuramoto, Duffing, Sprott, Lorenz, Rössler, May, Hénon, Chua, Gray-Scott, Mackey-Glass, Arnold), sin acceso al código de Fragua.

Arquitectura del código

  • Lenguaje y framework: C++ sobre JUCE 8.0.4, compilado con CMake.
  • Parámetros: un único árbol de estado con más de mil parámetros automatizables. Los de los diecisiete motores existen siempre en cada capa, por eso cambiar de motor no pierde ajustes.
  • Motores: cada sistema se integra por muestra, la mayoría con Runge-Kutta de cuarto orden. Los motores con altura escalan su paso de integración con la frecuencia de la nota, con un tope para seguir estables en los agudos; algunos (Sprott, Chua) se calibraron midiendo su periodo real con el banco de pruebas para que la nota caiga donde debe. Mackey-Glass incluye un detector de periodo que corrige el retardo en tiempo real.
  • Protección numérica: cada motor comprueba su estado en cada muestra y se reinicia si una variable se dispara.
  • Modulación: se calcula en bloques cortos. Las fuentes por nota viven dentro de cada voz; las globales se comparten. La matriz decide en cada bloque qué rutas son aplicables a cada destino.
  • Interfaz: dibujada con JUCE y un estilo propio; los halos de modulación leen el valor modulado real desde el hilo de audio sin bloquearlo.

El port del Deluge

Los efectos del rack DELUGE FX se copiaron del repositorio del firmware comunitario del Deluge. 31 archivos son idénticos byte a byte al original. Para compilarlos fuera del hardware se escribieron pequeños sustitutos de las cabeceras del firmware (memoria, parámetros, tablas) y una versión portátil de la librería vectorial Argon. Solo un archivo del firmware se modificó: el procesador de respuesta al impulso del delay analógico, para usar en ordenadores su ruta escalar, que el propio firmware documenta como equivalente.

El audio se convierte al punto fijo de 32 bits del Deluge, se procesa en bloques de 64 muestras con las mismas conversiones de parámetros que los menús del aparato, y vuelve a coma flotante. Como el Deluge trabaja a 44,1 kHz, las velocidades de los efectos se reescalan a la frecuencia del host para que los tiempos coincidan en milisegundos. Una ganancia fija de −12,96 dB compensa la etapa de salida del Deluge, de modo que el rack en neutro no cambia el nivel.

Caosmo 0.5 — User Manual

Introduction

Caosmo is a polyphonic synthesizer that plays no fixed waveforms and no samples. Each note starts a dynamical system, and what you hear is that system's trajectory, solved sample by sample. Oscillators that synchronise with each other, non-linear springs pushed to their limit, strange attractors, iterated maps, a chaotic electronic circuit, a chemical reaction on a ring of cells, a bowed string, a delay loop with memory and a map that meshes frequencies like the teeth of a gear.

The result is an instrument that behaves more like a physical object than an oscillator. It has calm regions and turbulent regions, it responds differently depending on how you arrive at a setting, and it never sounds exactly the same twice.

Chaos for musicians

You don't need maths to play Caosmo, but five ideas will save you a lot of time.

Dynamical systems

A dynamical system is a set of variables (position, velocity, temperature, phase…) and a rule saying how they change over time. A sine oscillator is the most boring dynamical system possible: it goes round in a circle forever. Caosmo's engines are systems with non-linearities: cubic terms, absolute values, saturation, products between variables. Those non-linearities are what make complex behaviour possible.

Attractors

Let a system with friction run, and its state ends up in a particular region: the attractor. It can be a point (the system stops: silence), a cycle (the system repeats a shape: a periodic tone), a torus (two superimposed cycles: a tone with beating) or a strange attractor (the system never repeats yet never escapes: a living, rough or noisy sound). The SCOPE's phase portraits literally show each lane's attractor.

Sensitivity to initial conditions

In a chaotic system, two almost identical states drift apart exponentially. That's why Caosmo starts each note with a different seed: two identical notes in a row are not identical, and a chord does not sound like transposed copies. If you want repeatability, several engines have a Note → Free menu that keeps the state between notes instead of resetting it.

Bifurcations

As you move a control parameter (K, Gamma, Chaos, Alpha, Sharp, R…) the kind of attractor can change suddenly: a tone splits into its sub-octave (period doubling), a beating appears, or the sound breaks into noise. Those points are bifurcations. They are the instrument's best material: modulate slowly around them with a VENV or an LFO and you will hear the system make up its mind. Many boundaries have hysteresis: the point where the system breaks on the way up is not where it recovers on the way down.

Synchronisation and locking

Several engines (Kuramoto, Circle Map, Mackey-Glass) try to lock: oscillators that end up beating together, frequencies that get trapped in simple ratios (1:1, 2:3, 3:4). Between the locking zones there are quasi-periodic and chaotic regions. That's where those engines get their metallic, vocal or trembling character.

How Caosmo protects the system

A non-linear system can run off to infinity. Every engine watches its state: if a variable blows up or stops being a valid number, the engine quietly restarts from a safe position. At worst you hear a small click, never a burst of level. All pitched engines also limit their integration step so they stay stable on high notes.

Architecture and signal flow

Every note you play takes a voice. Inside the voice, each lane that has an engine has its own complete chain:

  1. Engine: produces the signal by solving its system, tuned to the note if it is a pitched engine.
  2. Sub 1 (another instance of the same engine, 1–3 octaves down) and Sub 2 (a sine 1–2 octaves down) are added to the engine.
  3. Filter with 14 types.
  4. Envelope (VCA, and in LPG mode the filter too), scaled by velocity.

The voices of each lane are then summed on the lane bus, where EQ, drive, width, bass mono, pan, level and the sends to FX buses A–C are applied. The lane buses and the FX returns are summed and pass through the DELUGE FX rack (if enabled) and the master chain.

This split matters for modulation: whatever happens inside the voice (pitch, filter, engine, envelope, level) can be modulated per note; whatever happens on the lane bus (EQ, drive, width, pan, sends) can only be modulated by global sources, because separate notes no longer exist there.

Voices and voice stealing

Voices sets the maximum polyphony (1, 4, 8, 16, 32 or 64). When they run out, Caosmo first takes a free voice, then the oldest released voice, and as a last resort the oldest sounding voice. With Voices = 1 the synth is monophonic: with Legato on, tied notes do not retrigger the envelopes, and Glide slides the pitch (Fingered: only on tied notes; Always: always).

Per-note seed

Each note gets its own random number, used by the engines for their initial state, by drift, by the Note Random source and by the stereo placement of Voice Spread. That's why a preset feels alive even without modulation.

The lanes

Caosmo has three identical lanes (L1, L2, L3). Each note plays through every lane that has an engine and is powered. Use them as three stacked synths, as one sound and its sub-layers, or split them by MIDI channel for a keyboard split or a simple multitimbral setup.

DRIFT

Every note gets a fixed random deviation when it starts, like the tolerances of an analogue synth. It does not change during the note.

Level Pitch Filter Level
Off 0 0 0
Subtle ±3 cents ±1 semitone ±0.5 dB
Moderate ±8 cents ±3 semitones ±1.5 dB

Subtle on all three lanes thickens a chord without detuning it; Heavy on pitch gives the detuned chorus of an old tape.

PITCH

Pitch transposes ±36 semitones and Fine ±100 cents. Both are per-note modulation destinations: a slow LFO on Fine gives vibrato; a VENV on Pitch, pitch sweeps. Kuramoto

The system. In 1975 Yoshiki Kuramoto described how a population of oscillators with different frequencies can synchronise when coupled: fireflies that end up flashing together, pacemaker cells in the heart, applause that falls into step. Each oscillator turns at its natural frequency ωᵢ and is pulled towards the group's mean phase:

dθᵢ/dt = ωᵢ + K · r · sin(ψ − θᵢ)

where r (0–1) measures how closely the phases agree and ψ is the mean phase.

In Caosmo. Up to 12 phase oscillators. Their natural frequencies are spread around the note according to Ratio and Spread, and normalised so that their mean is the note. With low K each oscillator goes its own way: you hear a cluster of beating partials. As K rises there is a critical threshold where the group locks and the sound becomes a single, clean, glassy tone. That threshold has hysteresis: raising and lowering K does not pass through the same sounds.

Parameter Range (default) What it does
K 0–15 (2) Coupling strength. It scales with the note and with Spread, so the threshold is similar across the keyboard.
Spread 0–1 (0.5) Spread of the natural frequencies. More spread: partials further apart, and a higher K needed to lock.
N Osc 3–12 (6) Active oscillators. Those entering or leaving fade over 20 ms, so it can be modulated without clicks.
Out Mean, Coherent (Mean) Mean: the sum of all. Coherent: the sum weighted by how synchronised they are; almost silent when scattered, full when locked.
Ratio Asymmetric, Linear, Golden, Harmonic, Random (Asymmetric) Frequency layout. Linear: evenly spaced. Asymmetric: quadratic, denser at the bottom. Golden: golden-ratio positions, maximally inharmonic. Harmonic: 1, 1+Spread, 1+2·Spread…; with Spread = 1 it is the harmonic series. Random: fixed but irregular.

Sweet spots. Harmonic with Spread 1 and K between 2 and 6: an organ that detunes and pulls itself back together. Golden with K near the threshold and Out = Coherent: bells that appear and vanish. Modulate K with a slow LFO or an attractor for pads that drift in and out of phase (preset Glass Synchrony).

Duffing

The system. A spring whose stiffness grows with displacement and which has two rest positions (a double well), pushed by a periodic force:

ẍ + δẋ − x + k·x³ = γ·f(ωt)

With little force the mass oscillates inside one well: a round tone. With more force it leaps from one well to the other, sometimes regularly (sub-harmonics) and sometimes chaotically.

In Caosmo. The time base follows the note; the force oscillates at Omega times the note. Integration is fourth-order Runge-Kutta per sample.

Sprott

The system. Julien C. Sprott searched for the simplest possible chaotic systems. This one is a jerk flow (the derivative of acceleration):

x‴ = −a·ẍ − ẋ + |x| − 1

With a high, the system traces a clean cycle; as a falls it goes through a cascade of period doublings (the tone drops to the sub-octave, then the sub-octave of the sub-octave…) until it reaches chaos.

In Caosmo. Chaos, Damp and FB combine into the coefficient a, always inside the window where the system does not run away. The time base follows the note and Omega multiplies it.

Parameter Range (default) What it does
Chaos 0.1–3 (1) Lowers the coefficient a: from periodic tone to doublings and turbulence.

FB 0–1 (0) Adds a sinusoidal term that twists the orbit and limits the maximum chaos.
Out X, Y, Z, Blend (X) The coordinate you hear. X is the smoothest; Z the roughest.

Sweet spots. Raise Chaos slowly from 0.1 with Damp at 1: you will hear every period doubling. A long VENV on Chaos is the heart of the Bifurcations category.

Lorenz + Rössler

The system. Two of the most famous strange attractors. Lorenz (1963), a simplified model of atmospheric convection with its two "butterfly wings":

ẋ = σ(y − x) ẏ = x(ρ − z) − y ż = xy − βz (ρ = 28, β = 8/3)

Rössler (1976), a spiral that folds back on itself:

ẋ = −y − z ẏ = x + a·y ż = b + z(x − c) (a = b = 0.2)

In Caosmo. Both run at fixed speeds (Lorenz slow and growling, Rössler around 190 cycles per second) and are mixed. They do not follow the note: use Sub 2, a resonant filter or Pitch on the subs to give them pitch.

Logistic / Hénon

The system. Two maps: rules that compute the next value from the current one. The logistic map (May, 1976) is the most famous population equation in chaos theory:

xₙ₊₁ = r·xₙ·(1 − xₙ)

The Hénon map (1976) is its two-dimensional cousin:

xₙ₊₁ = 1 − a·xₙ² + yₙ yₙ₊₁ = b·xₙ

In Caosmo. With Clock on Per Sample (the default) both maps are iterated once per sample. At 48 kHz that produces structured noise: grainy, dusty, with fixed high tones whenever the map falls into a periodic window (r ≈ 3.83, for example, gives a period-3 cycle). In that mode it does not follow the note; with the Note clocks it does (see the table).

Chua

The system. Leon Chua's circuit (1983) was the first electronic circuit built to demonstrate chaos. It has a piecewise-linear non-linear resistor and produces the famous double-scroll attractor:

ẋ = α(y − x − f(x)) ẏ = x − y + z ż = −β·y

In Caosmo. Integrated per sample with Runge-Kutta 4. The time base follows the note; with Omega = 3.5 the fundamental lands on the note played.

Gray-Scott

The system. A reaction-diffusion model: two chemicals (U and V) that diffuse and react (U + 2V → 3V). Depending on the feed rate F and the kill rate k you get spots that divide like cells, stripes, waves or extinction. It is the same model that explains the spots on some animals' skin.

In Caosmo. A ring of 24 cells updated once per sample. The sound is a spatial projection of chemical V and of its change: it crackles when the "cells" divide or die. It does not follow the note, except through its built-in BPF.

Parameter Range (default) What it does

Drift 0–1 (0.3) Slowly oscillates F and k and, if the pattern dies, seeds new spots. At 0 the sound can die out for good on that note.
BPF 0–1 (0) Mixes in a band-pass tuned to the note: gives it pitch.
Q 0.5–15 (5) Resonance of that band-pass.

Sweet spots. The defaults (F 0.0367, k 0.0649) sit in the mitosis zone: spots that divide. BPF 0.8 with Q 10: tuned drops (Rain on Tin, Reaction Bells).

Lorenz Additive

The system. Additive synthesis: 32 sine partials on the note's harmonic series. Their amplitudes are not set by an envelope but by a slow Lorenz attractor: each partial reads a different combination of the three coordinates, so the spectrum rearranges itself continuously without repeating.

In Caosmo. The partials have a natural roll-off (about 1/n⁰·⁸⁵), and any that would exceed the Nyquist frequency are muted. With Engine HQ it is computed at twice the sample rate with a linear-phase decimation filter.

Bowed String

The system. A physical model of a bowed string (digital waveguide): the string is a delay line reflected at the bridge and the nut, and the bow interacts with it through a non-linear stick-slip friction curve. That mechanism is chaotic by nature: too little pressure and the string whistles, too much and it scratches.

In Caosmo. Two slightly detuned strings (±2 cents, left and right) and a body with three modes (230, 600 and 1600 Hz).

Mackey-Glass

The system. In 1977 Michael Mackey and Leon Glass proposed a model of blood-cell production with a delay: what the body produces today depends on what was there a time τ ago.

dy/dt = β · y(t−τ) / (1 + y(t−τ)ⁿ) − γ·y

With short delays the system oscillates; with high exponents n the oscillation doubles and becomes chaotic.

In Caosmo. The delay τ tunes itself: a period detector adjusts the loop until the oscillation matches the note. The result is feedback tones with stable pitch that can break into chaos.

Circle Map

The system. The circle map is the simplest model of two oscillators trying to lock, like the teeth of two gears or a pushed swing:

θₙ₊₁ = θₙ + Ω − (K/2π)·sin(2π·θₙ)

For each strength K there are ranges of Ω (the Arnold tongues) where the frequency ratio is trapped on a simple fraction: 1/2, 2/3, 3/4… Between them the motion is quasi-periodic and, with K above 1, chaotic.

In Caosmo. The map is iterated at a rate tied to the note and its phase becomes a waveform. A second map (the slave gear) runs at twice the rate and is coupled to the first.

Ecosystems

The system. Six models from biology and chemistry, taken from Nick Collins' SLUGens and Till Bovermann's ChaosUGens:

  • FitzHugh-Nagumo: a simplified neuron. Below a current threshold it does nothing; above it, it fires regular spikes.
  • Brusselator: a theoretical chemical clock. Past the Hopf bifurcation it oscillates on a limit cycle.
  • Oregonator: the model of the Belousov-Zhabotinsky reaction, the famous chemical cocktail that changes colour in cycles.
  • Lotka-Volterra: prey and predators. When prey are plentiful the predators grow, then eat them.

Membrane

The system. A falling, bouncing ball, like Dan Stowell's TBall UGen, striking a modal resonant body. Each hit excites up to 16 modes with the ratios of a circular membrane, a square plate, a free bar or a bell.

In Caosmo. When you play the note the ball drops from Height. Each bounce loses energy (Bounce Loss) and lands sooner, so the hits speed up until the ball comes to rest: a roll that closes on its own. A new note strikes the same body, which keeps ringing.

Four new shapes that remember their state from one cycle to the next. Skew sets how far they move and Dist where the steps come from.

Brownian Random walk that bounces off the edges: slow, organic drift.

Snapshots and morph

The EQ stores up to four curves (snapshots A–D):

  1. Set up a curve on A.
  2. Select B: the first time, B copies the current curve. Edit it.
  3. Repeat with C and D if you like.
  4. EQ Morph (0–100 %) travels through the used snapshots in the order A → B → C → D, interpolating frequencies logarithmically and gains linearly.

Selecting a snapshot moves the morph onto it, so you hear what you edit. RST returns to a single flat snapshot. EQ Morph is a modulation destination (for global sources): a slow LFO on it gives several bands of filtering moving together.

DELUGE FX

The DELUGE FX rack holds the effects from the Synthstrom Audible Deluge community firmware, copied from its open-source repository and compiled as is: the same 32-bit fixed-point arithmetic, the same 64-sample blocks and the same tables. It is an insert placed between the sum of lanes and FX and the master chain.

The controls use the Deluge's 0–50 menu scale (−25 to +25 for bipolar ones) and go through the firmware's own conversions. With everything at its neutral position the level does not change.

How they were made

The presets are described in text files, and a program generates, renders and measures them. Every preset is automatically levelled to about −18 dBFS RMS and checked so its true peak stays below −0.8 dBTP; how much the sound evolves over time is also measured, so presets tagged Evolving or Chaotic really are. That's why you can browse the bank without level jumps.

Tutorials

Every recipe starts from the initial patch: Settings → RESET TO INIT. The values are starting points: listen and adjust.

A pad that synchronises

  1. L1 Engine Kuramoto. Ratio Harmonic, Spread 0.6, N Osc 8, Out Coherent.
  2. ENV GEN: Attack 1.5 s, Release 3 s.
  3. FILTER: LPF 24 dB, Cutoff 3 kHz, Res 20 %.
  4. MODULATORS: LFO 1 on Random Smooth, Rate 0.08 Hz. ASSIGN → click K (on MAIN). In the matrix, Amount 0.35.
  5. Raise K until you hear the sound drift in and out of lock.
  6. FX1 send at −8 dB (bus A's Reverb).

For more life: Drift Pitch Subtle and, on L2, the same engine with Ratio Golden and Level −9 dB.

A double-well bass with bite

  1. L1 Duffing: Gamma 0.28, Delta 0.18, Omega 1, Out Position.
  2. Voices 1, Legato On, Glide 40 ms.
  3. FILTER: Ladder, Cutoff 400 Hz, Res 35 %, LPG Amp + Filt.
  4. ENV GEN: Attack 2 ms, Decay 350 ms, Sustain 40 %.
  5. Matrix: Velocity → L1 Motor 1 (Gamma), Amount 0.3, Curve Exp. Playing hard makes the mass jump between wells.
  6. OUTPUT: Drive 25 % Tape, Bass Mono 120 Hz.

Sand-and-metal percussion

  1. L1 Logistic/Henon: Morph 0.3, Smooth 0.55.
  2. ENV GEN: ADSR One-Shot, Attack 0.3 ms, Decay 90 ms, Sustain 0.
  3. FILTER: BPF, Res 60 %. Matrix: Keytrack → L1 Cutoff, Amount 0.5.
  4. L2 Chua Alpha 10.5, same envelope with Decay 40 ms, Level −6 dB: the "hit".
  5. Matrix: Note Random → L1 Cutoff, Amount 0.08: every hit sounds different.

A cloud that rewrites itself

  1. L1 Wave Grains: Size 60 ms, Count 10, Scatter 0.7, Spray 0.9, Jitter 0.2.
  2. Chaos Rossler, Chaos Rate 0.3 Hz, Chaos>X 0.6, Chaos>Y 0.5, Chaos>Fold 0.3, Tau 0.6. Grain Frozen.
  3. ENV GEN: Vactrol with Rise Slow 800 ms and Fall Slow 4 s.
  4. LFO 2 on Random S&H, Sync Host 1/8, to L1 Motor 5 (Size ms) with Amount 0.25. Turn on Loop Lock with Division 2 bars: the grain size changes the same way every time, like a sequence.
  5. In MASTER → FX, set slot 2 of bus B to Granular with Option Freeze, and raise the lane's FX2 send to −12 dB.

An expressive MPE cello

  1. Settings: MPE Lower, MPE PB Range 48 (or whatever your controller uses).
  2. L1 Bowed String: Press 0.5, Speed 0.5, Pos 0.18, Body 0.6, Rasp 0.15.
  3. ENV GEN: Vactrol, Rise Fast 20 ms, Fall Slow 1.2 s.
  4. Matrix: MPE Pressure → L1 Motor 2 (Speed) Amount 0.5; MPE Pressure → L1 Motor 1 (Press) Amount 0.25; MPE Slide → L1 Motor 3 (Pos) Amount 0.3.
  5. LFO 1 Poly, Sine 5.5 Hz, to L1 Fine Amount 0.08, with Fade In 600 ms: a late vibrato, like a player's.

A techno drone with the Deluge

  1. L1 Mackey-Glass: Sharp 0.45, Crackle 0.1, Octave Fixed. L2 Gray-Scott with BPF 0.6.
  2. LFO 1 Sync Host 1/16, Pulse, to L1 Level and L2 Level (negative Amount, −0.6): a rhythmic gate. Link Dual with Link Mode Divide: LFO 2 at half speed, to L2 Cutoff.
  3. MASTER → DELUGE: Deluge FX On; Mod FX Dimension (Depth 20); Delay Amount 18, Sync 1/8, Dotted, Analog On; Reverb Mutable Amount 15; Compressor Threshold 20, Blend 35.
  4. In REAPER, automate Deluge Stutter on the last beat of every four bars.

Writing a bifurcation

  1. L1 Sprott: Chaos 0.1, Damp 1, Out X.
  2. VENV 1: draw a slow ramp from 0 to 1 with a plateau at the end. Mode 1-Shot, Time 12 s, Voicing Poly.
  3. Matrix: VENV 1 → L1 Motor 1 (Chaos), Amount 0.7.
  4. Hold a note: the tone splits into sub-octaves and ends in turbulence. Aftertouch → L1 Motor 1 with Amount 0.2 lets you push it live.

Tuned rain with Poisson triggers

  1. L1 Noise: Type Dust2, Density 200, Key BPF 0.8, Q 18.
  2. ENV GEN: Attack 5 ms, Release 1 s. FILTER: Ladder, Cutoff 2 kHz, Res 40 %.
  3. MODULATORS → TRIGGER 1: Mode Dust, Rate 6 Hz, Output S&H Decay, Length 150 ms, Dist Beta.
  4. Matrix: Trig 1 → L1 Cutoff, Amount 0.4, and Trig 1 → L1 Motor 5 (Q), Amount 0.2.
  5. Macro 1 → Trig1 Prob: the macro thins or thickens the rain. To give every note its own character, Note Random → L1 Motor 2 with Note Random Dist on Gauss.

Performance and CPU

The cost depends on voices × lanes × engine. Some guidelines:

  • The lightest engines are Maps, Noise, Logistic/Henon, Duffing, Sprott, Chua and Circle Map. The heaviest are Lorenz Additive (with Engine HQ), Wave Grains with a high Count, Kuramoto with 12 oscillators, and Gray-Scott.
  • Sub 1 doubles the cost of that lane's engine; Sub 2 is free.
  • Poly modulators cost one instance per voice.
  • Lower Voices to what you need: 8 is usually enough for pads, 1–4 for basses and leads.
  • Switch Engine HQ off if you don't use Lorenz Additive or are short of CPU.
  • Switch unused lanes off with PWR (Mute does not save CPU).
  • Visualisers only use CPU while the window is open; close it or pause them in Settings.
  • In the DAW, render or freeze tracks in large mixes.

How it was made

Caosmo was built over five versions, from a playable core to a complete instrument with effects and binaries for three systems.

Research

The starting point was Fragua's public documentation: its three-lane architecture, the list of engines, the description of each control and the published demos. From there each system was reimplemented from its original equations in the scientific literature (Kuramoto, Duffing, Sprott, Lorenz, Rössler, May, Hénon, Chua, Gray-Scott, Mackey-Glass, Arnold), without access to Fragua's code.

Code architecture

  • Language and framework: C++ on JUCE 8.0.4, built with CMake.
  • Parameters: a single state tree with more than a thousand automatable parameters. The parameters of all seventeen engines always exist on every lane, which is why switching engines loses nothing.
  • Engines: each system is integrated per sample, most with fourth-order Runge-Kutta. Pitched engines scale their integration step with the note frequency, capped to stay stable in the treble; some (Sprott, Chua) were calibrated by measuring their real period with the test bench so the note lands where it should. Mackey-Glass includes a period detector that corrects the delay in real time.
  • Numerical safety: every engine checks its state on every sample and restarts if a variable blows up.
  • Modulation: computed in short blocks. Per-note sources live inside each voice; global ones are shared. On every block the matrix decides which routes apply to each destination.
  • Interface: drawn with JUCE in its own style; the modulation halos read the real modulated value from the audio thread without blocking it.

The Deluge port

The DELUGE FX effects were copied from the Deluge community firmware repository. 31 files are byte-identical to the original. To build them outside the hardware, small stand-ins were written for the firmware headers (memory, parameters, tables) along with a portable version of the Argon vector library. Only one firmware file was changed: the impulse-response processor of the analogue delay, so that computers use its scalar path, which the firmware itself documents as equivalent.

Audio is converted to the Deluge's 32-bit fixed point, processed in 64-sample blocks with the same parameter conversions as the device's menus, and converted back to floating point. Because the Deluge runs at 44.1 kHz, the effect rates are rescaled to the host sample rate so times match in milliseconds. A fixed −12.96 dB gain compensates the Deluge's output stage, so the rack at neutral does not change the level.

Presets

The 288 presets are written as text: each line sets the parameters that differ from the initial patch. A generator loads them into the real engine, renders them, measures their RMS level and true peak, levels them, checks their evolution over time and packs them into the plugin. The 128 experimental presets and the 32 from version 0.5 are produced by scripts that combines per-category design rules (which engines, which interconnected modulators, which macros).

Testing

  • A dedicated test bench with modes for engine stability, parameter sweeps, CPU use, loading every preset, the interface and the Deluge rack's gain.
  • AddressSanitizer and UndefinedBehaviorSanitizer builds with no errors.
  • pluginval (Tracktion) at strictness 7, including its thread-safety test, which uncovered a Mod FX bug in version 0.4 that was then fixed.
  • Continuous integration on GitHub Actions: every change is built for Linux, Windows and macOS, validated with pluginval and packaged.
